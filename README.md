# Bessem Jouini — Portfolio

React + Vite + Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Outputs static files to `dist/`.

## Deploy on Vercel
1. Push this folder to a GitHub repo.
2. Go to vercel.com → New Project → import the repo.
3. Vercel auto-detects Vite — click Deploy. No config needed.
4. Add your custom domain (from GitHub Student Pack) under Project Settings → Domains.

## Edit content
All portfolio content (skills, projects, experience, education) lives in
`src/App.jsx` as plain arrays near the top of the file — edit those to update the site.
